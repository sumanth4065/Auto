# Repo Rules

Keep these rules short and strict.

1. Make minimal scoped changes only.
2. Reuse existing helpers and patterns before adding abstractions.
3. Add or update nearest unit tests for every behavior change.
4. Do not modify Playwright suites under `tests/` unless requested.
5. No secrets, tokens, or environment-specific credentials in code.
6. Update concise documentation highlights for notable changes.
7. Do not add new Claude config files unless they remove repeated manual work.
